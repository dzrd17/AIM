ARCH · 면적 평면

CreateAreaPlan

선택한 레벨과 면적 체계에 대한 면적 평면도를 생성합니다. 이미 존재하는 면적 평면도는 그대로 사용하며 경계선은 작성하지 않습니다.

필수 패밀리 및 매개변수

이 기능을 작동하는 데 필요한 Revit 요소와 정보입니다.

이름 타입 설명
[이름 입력] [카테고리/타입] 기능 작동에 필요한 구체적인 정보 또는 속성 이름을 입력하세요.

사용 순서

  1. 실행 전 대상 요소, 활성 뷰, 링크 모델 또는 입력 파일이 이 기능의 설명과 맞는지 확인하세요.
  2. pyRevit 리본에서 CreateAreaPlan 버튼을 실행합니다.
  3. 선택창이나 입력창이 열리면 현재 모델의 작업 범위에 맞게 값을 확인합니다.
  4. 완료 후 모델 변경 결과와 pyRevit 결과창을 함께 확인합니다.
